# CodeMorph

[English](README.md) · Русский

CodeMorph — экспериментальный инструмент миграции C++ в Rust. Модель
предлагает исходный код, а компилятор и проверки поведения проверяют результат.

## Быстрый старт

Понадобятся Rust, Python 3.11+ и запущенный локальный Docker. Подключите установленную
модель CodeMorph или [совместимый API](docs/model-backends.md#настройка-модели).

```sh
docker pull rust:1-bookworm
cargo build --locked --workspace
./target/debug/codemorph migrate ./cpp --output ./migration-output --full
```

Команда `./bootstrap.sh` собирает и устанавливает CLI и Python runtime.
По умолчанию исполняемый файл устанавливается в `~/.local/bin`. Путь можно
задать через `CODEMORPH_INSTALL_DIR`.

Укажите `--model-dir PATH` для выбора конкретной модели. Без `--full`
выполняется проверка компиляции. С `--full` добавляется сравнение поведения
на воспроизводимых входах, задаваемых параметрами `--cases` и `--seed`.
Команда `codemorph migrate --help` выводит параметры CLI.

Отчёт находится в `migration-output/.codemorph/migration-report.json`.
Статус `verified` означает совпадение на выполненных проверках. Статус
`compiled` отражает успешную компиляцию. Перед использованием результата
проверьте отчёт и запустите тесты вашего проекта.

## Локальные данные

Храните модели в `models/`, результаты в `migration-output/` или `outputs/`,
а ключи — в переменных окружения. Эти каталоги исключены из Git.

## Лицензия

тестирования. Использование организацией или в коммерческой деятельности
требует отдельной письменной лицензии. [Текст лицензии](LICENSE)
